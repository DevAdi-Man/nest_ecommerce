# Design references used for this revision

- [Logo Design skill — Kaan Kızıltuğ](https://github.com/kaankiziltug/logo-design-skill/blob/main/skills/logo-design/SKILL.md): brief, distinct concepts, monochrome-first construction, outlined wordmarks, small-size variants and concept approval before identity rollout. The user rejected A–C and selected **H — Open Basket** from D–I. References were read for this task; no third-party scripts were executed or global skills installed.
- [Chart Design skill — Wyatt Brocato](https://github.com/thewyattbrocato/design-and-copy-skills/blob/main/skills/chart-design/SKILL.md): choose a chart for a specific comparison, zero baseline for bars, direct values, units, restrained emphasis, and an accompanying data table. The seller revenue chart explicitly uses illustrative data, not actual sales.
- [Lucide source](https://github.com/lucide-icons/lucide/tree/main/icons) and [license](https://lucide.dev/license): downloaded SVGs are imported as native editable vector layers. The full license, including inherited notices, is in `../assets/icons/LICENSE`.
- [FigCraft MCP](https://github.com/storytold/figcraft/blob/main/docs/mcp.md) and [control protocol](https://github.com/storytold/figcraft/blob/main/docs/control-protocol.md): native vertical-overflow frames and wheel-input verification in the actual running presenters.
- [Unsplash license](https://unsplash.com/license): four downloaded product photographs. Their exact download URLs are recorded in `../assets/sources.json`. The phone, headphones, shoes and backpack are sample design imagery; generic sample labels replace mismatched named-product placeholders. These images are not a verified product catalogue.

The second-round concepts and the selected logo are original SVG constructions; the wordmark is outlined from DejaVu Sans Bold. No stock icon was passed off as the brand logo. The selected mark remains the same construction in its primary, reversed, monochrome and small-size assets.
